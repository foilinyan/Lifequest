# Life Quest — Android MVP

Приложение жизненных достижений на Python + Kivy.

## Уже работает
- готовые ачивки;
- создание личных ачивок;
- описание, категория, редкость и награда XP;
- выполнение ачивки;
- уровни: новый уровень каждые 250 XP;
- история выполненных достижений;
- локальная SQLite-база;
- тёмный мобильный интерфейс;
- автоматическая сборка APK через GitHub Actions.

## Как получить APK с телефона

1. Создай новый пустой репозиторий на GitHub.
2. Распакуй ZIP и загрузи в репозиторий все файлы, включая папку `.github`.
3. Открой вкладку **Actions**.
4. Выбери **Build Android APK**.
5. Нажми **Run workflow**.
6. После завершения открой запуск и скачай артефакт `life-quest-apk`.
7. Распакуй скачанный ZIP — внутри будет APK.

Android может попросить разрешение на установку приложений из браузера или файлового менеджера.

## Запуск на ПК для проверки

```bash
python -m pip install kivy==2.3.1
python main.py
```
